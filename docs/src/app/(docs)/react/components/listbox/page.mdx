## Usage guidelines

- **Prefer Select for forms**: Use [Select](/react/components/select) instead of Listbox for selection in forms.
- **Multi-select support**: Set `multiple` to allow selecting more than one item. The value is then an array.
- **Provide an accessible name**: Prefer `<Listbox.Label>`, or provide an `aria-label` on `<Listbox.List>` when no visible label is rendered.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Listbox } from '@base-ui/react/listbox';

<Listbox.Root>
  <Listbox.Label />
  <Listbox.List>
    <Listbox.Item>
      <Listbox.ItemIndicator />
      <Listbox.ItemText />
    </Listbox.Item>
    <Listbox.Group>
      <Listbox.GroupLabel />
    </Listbox.Group>
  </Listbox.List>
</Listbox.Root>;
```

## Examples

### Multiple selection

Add the `multiple` prop to let users select more than one item. The value is an array of the selected items.

Clicking an item, or pressing <kbd>Space</kbd>, adds or removes it. Hold <kbd>Shift</kbd> and click to select a range.

Set `multiple="opt-in"` to make a press replace the selection instead, like a file manager. Clicking an item or pressing <kbd>Space</kbd> selects only that item. Hold <kbd>Ctrl</kbd>/<kbd>⌘</kbd> and click, or press <kbd>Ctrl</kbd>+<kbd>Space</kbd>, to add or remove an item, and hold <kbd>Shift</kbd> and click to select a range.
