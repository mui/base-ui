## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Toggle } from '@base-ui/react/toggle';

<Toggle.Root>
  <Toggle.Indicator />
</Toggle.Root>;
```

Rendering `<Toggle>` directly is deprecated. It still works and takes the same props, so replace it with `<Toggle.Root>`.

## Examples

### Animate icon path

Without `match`, the indicator stays mounted and reflects the pressed state through `data-pressed`.
Wrap an icon in it and use `data-pressed` to transition parts of the icon, such as the heart's filled path.

import { DemoToggleAnimateIconPath } from './demos/animate-icon-path';

<DemoToggleAnimateIconPath />

### Animate between icons

With `match`, each indicator mounts and unmounts as the pressed state changes.
Use `data-starting-style` and `data-ending-style` to animate one icon out while the other animates in.

import { DemoToggleAnimateBetweenIcons } from './demos/animate-between-icons';

<DemoToggleAnimateBetweenIcons />
