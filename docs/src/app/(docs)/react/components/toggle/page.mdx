## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Toggle } from '@base-ui/react/toggle';

<Toggle.Root>
  <Toggle.Indicator />
</Toggle.Root>;
```

## Examples

### Toggle icon

Use a pair of indicators to swap the icon when the toggle is pressed.
Set `match="pressed"` on the icon shown while the toggle is pressed, and `match="unpressed"` on the icon shown while it isn't.
Without `match`, an indicator always renders, and you can style it with `data-pressed`.
