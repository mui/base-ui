## Usage guidelines

- **Use for searchable actions**: Choose `FilterMenu` when users need to find an action. Use [Menu](/react/components/menu) for a short list that does not need search.
- **Use Combobox for values**: Choose [Combobox](/react/components/combobox) when users are selecting a value rather than running an action.
- **Name the filter input**: Give `<FilterMenu.Input>` an accessible name with `aria-label`, `aria-labelledby`, or a visible native `<label>`.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { FilterMenu } from '@base-ui/react/filter-menu';

<FilterMenu.Root>
  <FilterMenu.Trigger />
  <FilterMenu.Portal>
    <FilterMenu.Backdrop />
    <FilterMenu.Positioner>
      <FilterMenu.Popup>
        <FilterMenu.Arrow />

        <FilterMenu.Input />
        <FilterMenu.Clear />

        <FilterMenu.Status />
        <FilterMenu.Empty />

        <FilterMenu.List>
          <FilterMenu.Row>
            <FilterMenu.Item />
          </FilterMenu.Row>

          <FilterMenu.LinkItem />
          <FilterMenu.Separator />

          <FilterMenu.SubmenuRoot>
            <FilterMenu.SubmenuTrigger />
          </FilterMenu.SubmenuRoot>

          <FilterMenu.Group>
            <FilterMenu.GroupLabel />
          </FilterMenu.Group>

          <FilterMenu.RadioGroup>
            <FilterMenu.GroupLabel />
            <FilterMenu.RadioItem>
              <FilterMenu.RadioItemIndicator />
            </FilterMenu.RadioItem>
          </FilterMenu.RadioGroup>

          <FilterMenu.CheckboxItem>
            <FilterMenu.CheckboxItemIndicator />
          </FilterMenu.CheckboxItem>
        </FilterMenu.List>

        <FilterMenu.Viewport />
      </FilterMenu.Popup>
    </FilterMenu.Positioner>
  </FilterMenu.Portal>
</FilterMenu.Root>;
```

## Examples

### Command palette

Combine `FilterMenu` with [Dialog](/react/components/dialog) to create a command palette.
The `inline` prop renders the list directly inside the dialog without the menu's own popup parts; specify `open` together with it so the list is considered visible.
`autoHighlight="always"` keeps the first match highlighted so Enter always runs a command.

<DemoFilterMenuCommandPalette />

### Emoji picker

Set `grid` on the Root and wrap each row in `<FilterMenu.Row>` to create a searchable action grid.
Grid rows support only regular `<FilterMenu.Item>` actions.
Give any element between the list and its rows `role="presentation"`.

<DemoFilterMenuEmojiPicker />

### Async search

Pass `filter={null}` and fetch matches yourself to search a source too large to render, such as a server-side index.
Open with a short list of suggestions, return only the top matches for each query, and keep the previous results rendered while a request is pending.
Use `<FilterMenu.Status>` to announce the progress and how much of the source matched.

<DemoFilterMenuAsync />

### Virtualized

Efficiently handle large preknown lists using a virtualization library like `@tanstack/react-virtual`.
Pass the filtered item count to `virtualized` on the Root, give each rendered item its absolute `index`, and scroll the highlight into view with `onItemHighlighted`.
Filtering stays yours through `filter={null}`, and the virtualizer's overscan keeps keyboard navigation an adjacent item to move to.

<DemoFilterMenuVirtualized />

### Filtering items

Items match their rendered text by default. Use `label` to provide explicit searchable text and `keywords` for alternate terms.

```jsx title="Labels and keywords"
<FilterMenu.List>
  <FilterMenu.Item keywords={['edit name']}>Rename</FilterMenu.Item>
  <FilterMenu.Item label="Move to folder" keywords={['organize']}>
    Move
  </FilterMenu.Item>
</FilterMenu.List>
```

Groups with no matching items are hidden, including their labels. `FilterMenu.Empty` is shown when no items match and renders nothing otherwise.
Use `FilterMenu.Status` to announce other changing messages, such as asynchronous loading progress. It renders nothing while it has no children.

### Custom matching

Use `filter` to replace the default case-insensitive substring matching.
It receives the item's text, the trimmed query, and the item's `keywords`, so it decides whether keywords participate:

```jsx title="Custom filter"
<FilterMenu.Root
  filter={(itemText, query, keywords) =>
    itemText.startsWith(query) || (keywords?.some((keyword) => keyword.startsWith(query)) ?? false)
  }
>
  {/* menu parts */}
</FilterMenu.Root>
```

Pass `filter={null}` to turn matching off and render only the items you want yourself, such as when a server returns the results.
See [Async search](#async-search) for a complete example.

### Menus without a search field

`FilterMenu.Input` is optional. Omit it and the list itself holds focus, moves the highlight with the arrow keys, and matches typed characters against item text the way [Menu](/react/components/menu) does.
This suits a submenu that is short enough not to need its own search field while its parent still has one.

```jsx title="A submenu without a search field"
<FilterMenu.SubmenuRoot>
  <FilterMenu.SubmenuTrigger>Sort by</FilterMenu.SubmenuTrigger>
  <FilterMenu.Portal>
    <FilterMenu.Positioner>
      <FilterMenu.Popup>
        <FilterMenu.List>
          <FilterMenu.Item>Name</FilterMenu.Item>
          <FilterMenu.Item>Date modified</FilterMenu.Item>
        </FilterMenu.List>
      </FilterMenu.Popup>
    </FilterMenu.Positioner>
  </FilterMenu.Portal>
</FilterMenu.SubmenuRoot>
```

### Filterable submenus

Each `<FilterMenu.SubmenuRoot>` can have its own optional input, independently of the root menu. Add one when the submenu should be searchable.

```jsx title="A filterable submenu"
<FilterMenu.SubmenuRoot>
  <FilterMenu.SubmenuTrigger>More actions</FilterMenu.SubmenuTrigger>
  <FilterMenu.Portal>
    <FilterMenu.Positioner>
      <FilterMenu.Popup>
        <FilterMenu.Input aria-label="Filter more actions" />
        <FilterMenu.List>
          <FilterMenu.Item>Share</FilterMenu.Item>
          <FilterMenu.Item>Move</FilterMenu.Item>
        </FilterMenu.List>
      </FilterMenu.Popup>
    </FilterMenu.Positioner>
  </FilterMenu.Portal>
</FilterMenu.SubmenuRoot>
```
