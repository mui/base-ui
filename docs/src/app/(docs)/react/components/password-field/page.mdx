## Usage guidelines

- **Form controls must have an accessible name**: It can be created using a `<PasswordField.Label>` or the `Field` component. See the [forms guide](/react/handbook/forms).

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { PasswordFieldPreview as PasswordField } from '@base-ui/react/password-field';

<PasswordField.Root>
  <PasswordField.Label />
  <PasswordField.Group>
    <PasswordField.Input />
    <PasswordField.Toggle>
      <PasswordField.ToggleIndicator />
    </PasswordField.Toggle>
  </PasswordField.Group>
</PasswordField.Root>;
```

## Examples

### Animate icon path

Without `match`, the indicator stays mounted and reflects the visibility through `data-visible`.
Wrap an icon in it and use `data-visible` to transition parts of the icon, such as the eye's slash.

import { DemoPasswordFieldAnimateIconPath } from './demos/animate-icon-path';

<DemoPasswordFieldAnimateIconPath />

### Animate between icons

With `match`, each indicator mounts and unmounts as the visibility changes.
Use `data-starting-style` and `data-ending-style` to animate one icon out while the other animates in.

import { DemoPasswordFieldAnimateBetweenIcons } from './demos/animate-between-icons';

<DemoPasswordFieldAnimateBetweenIcons />
