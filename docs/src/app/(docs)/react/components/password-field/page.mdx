## Usage guidelines

- **Form controls must have an accessible name**: It can be created using a `<label>` element or the `Field` component. See the [forms guide](/react/handbook/forms).
- **Name an icon-only toggle**: Give `<PasswordField.Toggle>` a stable `aria-label`, such as `"Show password"`. `<PasswordField.ToggleIndicator>` is hidden from assistive technology, and the toggle's `aria-pressed` already announces whether the password is shown, so the label doesn't need to change.
- **Set `autoComplete` for new passwords**: The input defaults to `autoComplete="current-password"`. On sign-up or change-password forms, pass `autoComplete="new-password"` so browsers and password managers offer to generate one.
- **Use one input per root**: The toggle controls a single `<PasswordField.Input>`. Give a "confirm password" input its own `<PasswordField.Root>`.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { PasswordFieldPreview as PasswordField } from '@base-ui/react/password-field';

<PasswordField.Root>
  <PasswordField.Input />
  <PasswordField.Toggle>
    <PasswordField.ToggleIndicator />
  </PasswordField.Toggle>
</PasswordField.Root>;
```

## Examples

### Toggle icon

`<PasswordField.ToggleIndicator>` always renders and reflects the visibility through `data-visible`.
To swap icons instead, pass `match="password-visible"` or `match="password-masked"` so each indicator renders only in that state.
